# 🤖 Mini Alexa - Virtual AI Assistant

A beginner-friendly, terminal-based Virtual AI Assistant built using Python.

## 📌 Project Overview

Mini Alexa is an offline, rule-based virtual assistant that can understand simple commands and perform different tasks such as checking the date and time, doing calculations, telling jokes, giving motivational quotes, playing a guessing game, and demonstrating simple AI/ML concepts.

## ✨ Features

- 👋 Personalized greeting
- 🧑 Remembers user's name during the session
- 📅 Current date
- ⏰ Current time
- 🧮 Basic calculator
- 😂 Random jokes
- 💡 Motivational quotes
- 🧠 Random facts
- 🎮 Number guessing game
- 💭 Activity recommendation
- 🤖 Simple perceptron demonstration
- 📖 Help menu
- 👋 Graceful exit
- 🔍 Simple keyword and pattern matching
- 🛡️ Friendly response for unknown commands

## 🛠️ Technologies Used

- Python 3.x
- Python Standard Library
- Terminal / Command Prompt
- VS Code
